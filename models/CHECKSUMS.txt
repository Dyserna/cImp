# SHA-256 checksums for the model blobs bundled into the portable releases.
#
# Format: one `<sha256>  <filename>` per line (paths relative to models/).
# Matches `sha256sum`'s output so it pipes into `sha256sum -c` if desired.
#
# The blobs themselves are NOT in git. They used to be Git-LFS files, but
# CI pulls exhausted the LFS bandwidth quota; they are now assets on the
# `models-v1` GitHub release (our own mirror, so the project doesn't go
# dark if upstream HuggingFace moves or rate-limits — and asset downloads
# are unmetered). This file is the manifest that drives
# scripts/fetch-models.ps1 / .sh (download + verify; also run by the
# release workflow) and scripts/publish-models-release.ps1 (maintainer
# upload).
#
# Upstream provenance, for regenerating the mirror:
# Source: https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX
# Model file (kokoro-v1.0.onnx): renamed from onnx/model.onnx in the repo.
# Voicepacks (voices/*.bin): one per voice from voices/ in the repo.
#
# V6-01 speech-to-text (Whisper). The full zip bundles the default ggml model
# `ggml-small.bin` (MIT). Downloaded from
# https://huggingface.co/ggerganov/whisper.cpp on 2026-06-14.
#
# ─────────────────────────────────────────────────────────────────────────────
# V32 injection detection (Llama Prompt Guard 2, 22M) — USER-INSTALLED, NOT
# BUNDLED AND NOT MIRRORED. This is the one model in this file the project does
# not ship.
#
# Decision, 2026-08-08: cImp does not host these weights. They are under the
# Llama Community Licence — unlike Kokoro (Apache-2.0) and Whisper (MIT),
# mirroring them onto the `models-v1` release would be redistribution with
# attribution and acceptable-use conditions attached, for a layer that is
# optional. An ungated third-party ONNX export already exists, so a user who
# wants the layer fetches it directly and the licence travels with it.
#
# The three lines at the end of this block stay COMMENTED, permanently. Every
# uncommented line here is a download instruction for scripts/fetch-models.*,
# which pull from the `models-v1` release — and these assets are deliberately
# not there. They are recorded so a user can VERIFY what they downloaded, not
# so anything can fetch it. Do not uncomment them.
#
# To install the classifier screen (entirely optional):
#
#   1. Fetch two files from
#      https://huggingface.co/gravitee-io/Llama-Prompt-Guard-2-22M-onnx
#      (ungated — no HF account needed; ships LICENSE + NOTICE alongside, which
#      is how the Llama terms reach you rather than us):
#
#        model.onnx        284 MB  fp32, best accuracy
#        model.quant.onnx   72 MB  int8, ~4x smaller — rename to model.onnx
#        tokenizer.json     8.6 MB
#
#      Take ONE of the two ONNX files. The loader looks for exactly
#      `model.onnx`, so if you take the quantized build, rename it.
#
#   2. Place them at models/promptguard2-22m/{model.onnx,tokenizer.json}
#      (beside kokoro-v1.0.onnx — `<exe-dir>/../models/`).
#
#   3. Verify against the digests below, then restart cImp. Settings → Tools →
#      Detection flips from "weights not installed" to the model directory.
#
# Any ONNX export works, not just this one: opset 14+, dynamic batch + sequence
# axes, int64 `input_ids`/`attention_mask`, and a 1-logit or 2-logit head — see
# offload/detection/classifier.rs::score_from_logits. The digests below pin the
# specific build above; a different export will not match them, which is fine.
#
# Without the weights the classifier screen is gracefully inert: cImp logs one
# line at startup, Settings shows "weights not installed", and the YARA
# signature screen carries detection alone. That is the state of every install
# by default, and it is a supported configuration — not a degraded one.
#
