# SHA-256 checksums for the model blobs bundled into the portable releases.
#
# Format: one `<sha256>  <filename>` per line (paths relative to models/).
# Matches `sha256sum`'s output so it pipes into `sha256sum -c` if desired.
#
# The blobs themselves are NOT in git. They used to be Git-LFS files, but
# CI pulls exhausted the LFS bandwidth quota; they are now assets on the
# `models-v1` GitHub release (our own mirror, so the project doesn't go
# dark if upstream HuggingFace moves or rate-limits — and asset downloads
# are unmetered). This file is the manifest that drives
# scripts/fetch-models.ps1 / .sh (download + verify; also run by the
# release workflow) and scripts/publish-models-release.ps1 (maintainer
# upload).
#
# Upstream provenance, for regenerating the mirror:
# Source: https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX
# Model file (kokoro-v1.0.onnx): renamed from onnx/model.onnx in the repo.
# Voicepacks (voices/*.bin): one per voice from voices/ in the repo.
#
# V6-01 speech-to-text (Whisper). The full zip bundles the default ggml model
# `ggml-small.bin` (MIT). Downloaded from
# https://huggingface.co/ggerganov/whisper.cpp on 2026-06-14.
